## 1. Project Overview

This project develops an end-to-end machine learning system for predicting the nightly price of Airbnb listings in New York City.

The project covers the complete machine learning workflow:

- Data loading and exploration
- Data cleaning
- Exploratory Data Analysis (EDA)
- Feature engineering
- Feature selection
- Missing-value handling
- Data preprocessing
- Regression model development
- Model comparison
- Hyperparameter tuning
- Model evaluation
- Model pipeline creation
- Streamlit application development

The final system allows a user to enter Airbnb listing characteristics and receive an estimated nightly price.
